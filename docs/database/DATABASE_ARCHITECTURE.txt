A. KHÁCH HÀNG & THÔNG TIN CÁ NHÂN (Customer Profile)
═══════════════════════════════════════════════════════

    Customer (PK: customer_id)
    ├─ customer_id (BIGINT, PK)
    ├─ user_id (BIGINT, FK → User)
    ├─ full_name (NVARCHAR(150))
    ├─ age (INT)
    ├─ monthly_income (NUMERIC(18,2))
    ├─ credit_score (INT)
    ├─ employment_status (NVARCHAR(50))
    ├─ created_at (DATETIME2)
    ├─ updated_at (DATETIME2)
    └─ Relationships:
        ├─ Customer_Employment (1:N) - Lịch sử việc làm
        ├─ FINANCIAL_INDICATOR (1:N) - Chỉ số tài chính
        ├─ Customer_Payment_Statistics (1:1) - Thống kê thanh toán
        ├─ Loan_Application (1:N) - Các hồ sơ vay
        ├─ Loan_Facility (1:N) - Các khoản vay
        ├─ Alert (1:N) - Cảnh báo rủi ro
        └─ RISK_PREDICTION (1:N) - Dự đoán rủi ro

    Customer_Employment (PK: employment_id)
    ├─ employment_id (BIGINT, PK)
    ├─ customer_id (BIGINT, FK)
    ├─ company_name (NVARCHAR(200))
    ├─ position (NVARCHAR(100))
    ├─ years_of_experience (INT)
    ├─ monthly_income (NUMERIC(18,2))
    ├─ created_at (DATETIME2)
    └─ Purpose: Theo dõi lịch sử việc làm, chuyển công ty, tăng lương

    FINANCIAL_INDICATOR (PK: indicator_id)
    ├─ indicator_id (BIGINT, PK)
    ├─ customer_id (BIGINT, FK)
    ├─ dti_ratio (NUMERIC(5,2)) - Debt to Income Ratio
    ├─ monthly_expense (NUMERIC(18,2))
    ├─ asset_value (NUMERIC(18,2))
    ├─ liquid_assets (NUMERIC(18,2))
    ├─ reported_date (DATETIME2)
    ├─ updated_at (DATETIME2)
    └─ Purpose: Theo dõi chỉ số tài chính để đánh giá khả năng trả nợ

    Customer_Payment_Statistics (PK: stats_id)
    ├─ stats_id (BIGINT, PK)
    ├─ customer_id (BIGINT, FK) - UNIQUE
    ├─ total_outstanding (NUMERIC(18,2)) - Tổng dư nợ
    ├─ total_violations (INT) - Số lần vi phạm
    ├─ on_time_payment_rate (NUMERIC(5,2)) - Tỷ lệ trả đúng hạn (%)
    ├─ recent_risk_upgrade (INT) - Số lần nâng cấp rủi ro (6 tháng gần)
    ├─ recent_risk_downgrade (INT) - Số lần hạ cấp rủi ro (6 tháng gần)
    ├─ last_updated (DATETIME2)
    └─ Purpose: Tóm tắt nhanh thống kê khách hàng


B. QUY TRÌNH VAY & KHOẢN VAY THỰC TẾ (Lending Process)
═══════════════════════════════════════════════════════

    Loan_Application (PK: application_id)
    ├─ application_id (BIGINT, PK)
    ├─ customer_id (BIGINT, FK)
    ├─ loan_amount (NUMERIC(18,2))
    ├─ loan_term (INT) - Số tháng
    ├─ loan_purpose (NVARCHAR(200))
    ├─ loan_status (NVARCHAR(50)) - pending, approved, rejected, disbursed
    ├─ applied_at (DATETIME2)
    ├─ created_at (DATETIME2)
    └─ Relationships:
        ├─ Loan_Facility (1:N) - 1 application có thể có nhiều facility
        └─ RISK_PREDICTION (1:N) - Đánh giá rủi ro cho application

    Loan_Facility (PK: facility_id)
    ├─ facility_id (BIGINT, PK)
    ├─ application_id (BIGINT, FK)
    ├─ customer_id (BIGINT, FK)
    ├─ facility_amount (NUMERIC(18,2))
    ├─ disbursed_amount (NUMERIC(18,2))
    ├─ interest_rate (NUMERIC(5,2))
    ├─ facility_status (NVARCHAR(50)) - active, closed, suspended, defaulted
    ├─ disbursed_date (DATETIME2)
    ├─ created_at (DATETIME2)
    └─ Relationships:
        ├─ Loan_Repayment_Schedule (1:N) - Lịch trả nợ dự kiến
        ├─ Loan_Payment (1:N) - Thanh toán thực tế
        ├─ Loan_Delinquency (1:N) - Nợ quá hạn
        ├─ Loan_Classification (1:N) - Phân loại rủi ro (Group 1-5)
        ├─ Transaction_Log (1:N) - Lịch sử giao dịch
        ├─ Loan_Status_Migration (1:N) - Di chuyển nhóm nợ
        ├─ Provision_Allocation (1:N) - Dự phòng
        └─ Alert (1:N) - Cảnh báo

    Loan_Repayment_Schedule (PK: schedule_id)
    ├─ schedule_id (BIGINT, PK)
    ├─ facility_id (BIGINT, FK)
    ├─ schedule_number (INT) - Kỳ thứ mấy (1, 2, 3...)
    ├─ due_date (DATETIME2)
    ├─ principal_due (NUMERIC(18,2))
    ├─ interest_due (NUMERIC(18,2))
    ├─ total_due (NUMERIC(18,2))
    ├─ created_at (DATETIME2)
    └─ Purpose: Lịch trả nợ dự kiến

    Loan_Payment (PK: payment_id)
    ├─ payment_id (BIGINT, PK)
    ├─ facility_id (BIGINT, FK)
    ├─ schedule_id (BIGINT, FK)
    ├─ payment_amount (NUMERIC(18,2))
    ├─ principal_paid (NUMERIC(18,2))
    ├─ interest_paid (NUMERIC(18,2))
    ├─ penalty_paid (NUMERIC(18,2))
    ├─ payment_date (DATETIME2)
    ├─ payment_method (NVARCHAR(50)) - bank_transfer, cash, check...
    ├─ created_at (DATETIME2)
    └─ Purpose: Ghi nhận thanh toán thực tế

    Loan_Delinquency (PK: delinquency_id) ⭐ NEW
    ├─ delinquency_id (BIGINT, PK)
    ├─ facility_id (BIGINT, FK)
    ├─ original_due_date (DATETIME2)
    ├─ last_payment_date (DATETIME2)
    ├─ current_overdue_days (INT)
    ├─ principal_outstanding (NUMERIC(18,2))
    ├─ interest_outstanding (NUMERIC(18,2))
    ├─ penalty_outstanding (NUMERIC(18,2))
    ├─ delinquency_status (NVARCHAR(50)) - current, resolved, escalated
    ├─ escalation_level (INT) - 0=none, 1=notice, 2=formal demand, 3=legal
    ├─ delinquency_start_date (DATETIME2)
    ├─ last_action_date (DATETIME2)
    ├─ expected_resolution_date (DATETIME2)
    ├─ created_at (DATETIME2)
    ├─ updated_at (DATETIME2)
    └─ notes (NVARCHAR(MAX))
    └─ Purpose: Theo dõi khoản vay quá hạn và escalation

    Loan_Classification (PK: classification_id) ⭐ NEW
    ├─ classification_id (BIGINT, PK)
    ├─ facility_id (BIGINT, FK)
    ├─ group_id (INT, FK → Risk_Group) - Group 1-5 (SBV)
    ├─ days_overdue (INT)
    ├─ outstanding_principal (NUMERIC(18,2))
    ├─ provision_amount (NUMERIC(18,2))
    ├─ classification_status (NVARCHAR(50)) - active, archived, reassessed
    ├─ classified_by (BIGINT, FK → User)
    ├─ classified_at (DATETIME2)
    ├─ updated_at (DATETIME2)
    └─ notes (NVARCHAR(MAX))
    └─ Purpose: Phân loại rủi ro theo quy định SBV (Group 1-5)

    Loan_Status_Migration (PK: migration_id)
    ├─ migration_id (BIGINT, PK)
    ├─ facility_id (BIGINT, FK)
    ├─ from_group_id (INT) - Nhóm rủi ro cũ
    ├─ to_group_id (INT) - Nhóm rủi ro mới
    ├─ migration_date (DATETIME2)
    ├─ reason (NVARCHAR(500))
    ├─ created_at (DATETIME2)
    └─ Purpose: Theo dõi di chuyển nhóm nợ theo thời gian

    Transaction_Log (PK: transaction_id)
    ├─ transaction_id (BIGINT, PK)
    ├─ facility_id (BIGINT, FK)
    ├─ transaction_type (NVARCHAR(50)) - disbursement, payment, penalty, write-off
    ├─ transaction_amount (NUMERIC(18,2))
    ├─ transaction_date (DATETIME2)
    ├─ description (NVARCHAR(500))
    ├─ created_at (DATETIME2)
    └─ Purpose: Lịch sử giao dịch liên quan khoản vay

    Monthly_Delinquency (PK: monthly_delinq_id)
    ├─ monthly_delinq_id (BIGINT, PK)
    ├─ month (NVARCHAR(20)) - YYYY-MM format
    ├─ total_facilities (INT) - Tổng số facility
    ├─ delinquent_facilities (INT) - Số facility quá hạn
    ├─ total_outstanding (NUMERIC(18,2)) - Tổng dư nợ
    ├─ total_delinquent (NUMERIC(18,2)) - Tổng nợ quá hạn
    ├─ npl_ratio (NUMERIC(5,2)) - Tỷ lệ NPL (%)
    ├─ created_at (DATETIME2)
    └─ Purpose: Tóm tắt nợ xấu hàng tháng

    Alert (PK: alert_id)
    ├─ alert_id (BIGINT, PK)
    ├─ facility_id (BIGINT, FK)
    ├─ customer_id (BIGINT, FK)
    ├─ alert_type (NVARCHAR(50)) - overdue, high_pd, risk_upgrade
    ├─ severity (NVARCHAR(20)) - low, medium, high, critical
    ├─ message (NVARCHAR(500))
    ├─ is_resolved (BIT)
    ├─ created_at (DATETIME2)
    ├─ resolved_at (DATETIME2)
    └─ Purpose: Cảnh báo rủi ro (quá hạn, PD cao, nâng cấp rủi ro)

    ├─ model_id (INT, FK)

    ├─ coefficient_value (NUMERIC(10,6))

    └─ Purpose: Theo dõi các version model

KEY METRICS & KPIs
═══════════════════

1. NPL Ratio (Non-Performing Loan)
   = Total Facility in Group 3-5 / Total Outstanding

2. PD (Probability of Default)
   = Số lượng default / Số lượng facility (tương ứng thời gian)

3. LGD (Loss Given Default)
   = Thực tế Loss / Outstanding Amount at Default

4. EAD (Exposure at Default)
   = Tổng tiền gốc + lãi phát sinh tới ngày default

5. On-Time Payment Rate
   = Số lần thanh toán đúng hạn / Tổng số kỳ thanh toán

6. DTI Ratio (Debt to Income)
   = Total Outstanding / Monthly Income

7. Portfolio Risk Score
   = Weighted Average Risk Score của tất cả loans
